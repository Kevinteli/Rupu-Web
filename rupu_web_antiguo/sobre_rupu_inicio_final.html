Validación de Control Distribuido

La plataforma RÜPÜ permite a los investigadores implementar y probar estrategias de control cooperativo. A través de nuestra API en JetBrains Mono, es posible configurar parámetros cinemáticos y dinámicos con precisión milimétrica. 

// Configuración de Platooning RÜPÜ
RobotAgent agent = new RobotAgent("RU-01");
agent.setController(new PIDLeaderFollower(0.5, 0.1, 0.01));
agent.connectToSwarm("swarm_net_01");
agent.startFormation();
