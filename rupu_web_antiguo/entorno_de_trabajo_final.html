Entorno de Trabajo

Configuración inicial del software necesario para la implementación del sistema de control multivariable en plataformas RÜPÜ.

1

Instalación de Core Software

Para comenzar con el desarrollo, es imperativo contar con las versiones estables de los compiladores e intérpretes. Se recomienda el uso de las versiones especificadas para garantizar compatibilidad con las librerías de control.

  • download

    Arduino IDE v2.1.1

    Entorno de desarrollo para la carga de firmware en controladores ESP32.

  • terminal

    Python 3.x.x

    Necesario para la telemetría y el procesamiento de datos en tiempo real.

2

Configuración de Arduino

Para habilitar el soporte de tarjetas ESP32 en el IDE, debe agregar la URL del gestor de tarjetas en Preferencias:

https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json

info Nota técnica: Instale la versión 'ESP32 by Espressif Systems' desde el Board Manager tras agregar el link.

3

Entorno Python y Pip

Configure el entorno virtual para evitar conflictos de dependencias. Ejecute los siguientes comandos en su terminal:

# Crear entorno virtual Bash
python -m venv rupu_env
# Activar entorno (Windows)
.\rupu_env\Scripts\activate
# Instalación de dependencias críticas
pip install numpy scipy matplotlib pyserial
