Programación y Control

Configuración de red descentralizada y flujos de trabajo secuenciales para el control del sistema robótico RÜPÜ.

hub

Topología Leader/Follower

El sistema utiliza una arquitectura de red donde una unidad central coordina las peticiones mientras los periféricos ejecutan tareas locales de baja latencia.

Flujo de Carga Secuencial

1

Inicialización de Kernel

Carga los drivers base y el sistema de gestión de memoria del robot.

2

Handshake de Red

Sincronización de reloj maestro y validación de IPs según la tabla de mapping.

3

Inyección de Script

Despliegue de binarios .hex o scripts .py en la memoria flash de cada unidad.

Paso 2
