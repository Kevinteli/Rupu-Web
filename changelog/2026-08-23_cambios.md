# Changelog - 23 de Agosto de 2026

En esta sesión extensa se comenzó trabajando en la corrección de múltiples bugs y errores de diseño visual, para luego realizar una reestructuración profunda de la arquitectura del proyecto y añadir nuevas funcionalidades (3D) en la aplicación web RÜPÜ:

### 1. Reestructuración y Arquitectura
* **Unificación SPA:** Se migró el proyecto de tener múltiples archivos `.html` independientes a una arquitectura Single Page Application (SPA), centralizando todo el contenido en un único `index.html` para una navegación fluida sin recargas.
* **Separación de Responsabilidades:** Se diseñó una estructura de directorios típica y ordenada, separando estrictamente el código en archivos `.html` (estructura), `.css` (estilos) y `.js` (lógica e interacciones).
* **Resolución de Bugs Iniciales:** Se corrigieron múltiples errores de visualización, tipografía desajustada y colores inconsistentes heredados de las versiones previas.
### 2. Navegación y Router SPA
* **Botones Hero:** Se vincularon los botones principales ("Explorar Guía Técnica" y "Ver Demostraciones") al sistema de navegación Single Page Application (SPA).
* **Corrección de Estilos en Router:** Se arregló un conflicto crítico en `router.js` donde el sistema borraba los diseños personalizados de los botones. Ahora el router respeta las clases de Tailwind de los botones y solo aplica estilos de navegación a los enlaces del menú lateral.
* **Enlace Externo:** Se modificó el botón del Repositorio GitHub en el pie de página para que se abra en una pestaña nueva sin sacar al usuario de la aplicación.

### 3. Interfaz y Diseño (UI/UX)
* **Carrusel de Instituciones:** Se implementó una franja animada (marquee) infinita en la parte inferior del inicio con los logos de las instituciones. La animación se detiene fluidamente al pasar el cursor.
* **Modal de Logos (Lightbox):** Se creó una ventana flotante (modal) que se abre al hacer clic en cualquier logo del carrusel para verlo en detalle. Se corrigió su centrado en pantalla habilitando propiedades de Flexbox mediante JavaScript.
* **Ajuste del Popup de Ayuda:** Se movió el banner de "Ayuda técnica" del lado izquierdo al lado derecho para evitar que obstruyera los botones principales.
* **Galería de Demostraciones:** Se añadieron márgenes laterales y límites de ancho (`px-gutter`, `max-w`) al contenedor de la galería para evitar que el contenido se estirara de forma antiestética hasta los bordes tras la eliminación del menú lateral.
* **Mejora del Fondo Hero:** Se reemplazó la máscara negra sólida del 85% por un degradado horizontal elegante. Esto mejoró drásticamente la visibilidad del fondo (robots) sin perder la legibilidad del texto blanco principal.

### 4. Integración 3D (Visor RÜPÜ)
* **Implementación de `<model-viewer>`:** Se instaló la librería oficial de Google para visualización 3D y se inyectó el componente en la sección de "Armado".
* **Conexión de Archivo Local:** Se enlazó exitosamente el archivo exportado de Fusion 360 (`Idea soporte Horn V1 v1.glb`) al visor 3D.
* **Botonera de Control de Cámara:** Se añadió una interfaz flotante sobre el modelo 3D con botones de acceso rápido para controlar vistas predefinidas: Frontal, Lateral, Superior e Isométrica.
* **Optimización de Interacción:** Se ajustó el comportamiento de la animación de "pista interactiva" (el cursor/mano virtual) para que desaparezca de forma permanente en cuanto el usuario utiliza los botones de cámara, evitando molestias visuales.
